# 🛃 Despachante Aduaneiro | Victor Sanches (Viracopos - VCP)

Repositório oficial do site institucional desenvolvido para prestação de serviços de **Desembaraço Aduaneiro Agilizado e Presencial** no Aeroporto Internacional de Viracopos (VCP), em Campinas - SP.

🔗 **Acesse o site online:** [despachante-victorsanches.vercel.app](https://despachante-victorsanches.vercel.app)[cite: 1]

---

## 🚀 Sobre o Projeto

Este projeto consiste em uma landing page/site institucional voltado para conversão e contato direto de clientes que precisam de liberação rápida de mercadorias, vistorias físicas, conferência documental e assessoria aduaneira presencial no TECA Viracopos[cite: 1].

O layout foi planejado para transmitir confiabilidade, agilidade e clareza nos serviços prestados, contando com botões de chamada para ação (CTA) voltados para atendimento via WhatsApp e e-mail[cite: 1].

---

## 🛠️ Tecnologias Utilizadas

*   **HTML5 / CSS3** (Estruturação e estilização responsiva)
*   **JavaScript** (Interatividade e navegação fluida)
*   **Vercel** (Hospedagem e deploy contínuo)

---

## 📌 Seções do Site

*   **Início / Hero Section:** Destaque para atuação presencial no TECA Viracopos e chamadas rápidas para WhatsApp[cite: 1].
*   **Sobre Mim:** Apresentação da experiência e atuação profissional como despachante aduaneiro autônomo.
*   **Serviços:** Detalhamento dos processos de importação, exportação, liberação alfandegária e vistorias.
*   **Guia Viracopos:** Informações úteis sobre a operação no aeroporto.
*   **FAQ:** Respostas rápidas para as principais dúvidas de importadores e transportadores.
